欢迎使用

本管理后台用于维护客服 Copilot 系统的多 Agent 配置与 RAG 知识库。

  • 在 Agent 管理 中维护 Agent 名称、身份使命、前置 Prompt、最大决策轮数。
  • 在 知识库管理 中维护 Agent 所用的 RAG 文档，保存后会自动重建向量索引。
  • 在 在线对话 中向 Agent 发送消息，实时查看 ReAct 决策轨迹。

对外接口

  • POST /copilot/chat 提交客户消息，返回 uuid
  • GET  /copilot/chat/result?uuid=xxx 查询任务步骤与最终回复
